# 30-days-of-engineering

This repository is my 30-day learning journal focused on becoming a stronger software engineer.

Over the next 30 days, I’ll be consistently documenting my learnings across:

- Data Structures & Algorithms (Striver’s Sheet + Leetcode)
- System Design fundamentals
- Backend engineering concepts
- Distributed systems & cloud fundamentals
- Interesting engineering deep dives and industry trends

The goal is not just solving problems, but building deeper engineering intuition, improving technical communication, and creating a structured knowledge base I can revisit later.

## Daily Structure

Each day will generally include:

### DSA
- Problem patterns
- Complexity analysis
- Key learnings
- Common mistakes

### System Design
- One core concept or architecture topic
- Notes, tradeoffs, and practical understanding

### Engineering Deep Dive
Examples:
- How Claude Code memory works
- What Forward Deployed Engineers do
- Why vector databases exist
- Behind-the-scenes of modern AI systems
- Distributed systems concepts
- Infrastructure and scaling topics

## Why I’m Doing This

I wanted a way to stay accountable without the pressure of posting daily on social media.
